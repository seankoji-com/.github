# Support

Use the affected repository's issue forms for reproducible bugs and bounded
work. Use Discussions when the repository enables them and the request is a
question, idea, or open-ended design topic.

Before posting, search existing issues and documentation. Remove credentials,
personal data, private hostnames, and private logs from screenshots and text.

Security reports do not belong in support issues. Follow
[SECURITY.md](SECURITY.md) instead.
